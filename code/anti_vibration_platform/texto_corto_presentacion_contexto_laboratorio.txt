Proyecto propuesto:
Se desarrollara una plataforma antivibratoria activa para un sensor de ultrasonido empleado en pruebas de laboratorio para inspeccion de papas. Durante la medicion, las vibraciones de la mesa o base alteran la posicion del sensor y producen errores en la distancia medida. Por esta razon, el problema se plantea como rechazo de perturbaciones: se busca que la plataforma donde esta montado el sensor permanezca lo mas inmovil posible aunque la base vibre. Para ello se modela el sistema como una masa unida a la base mediante resorte y amortiguador, con un actuador electromecanico que aplica una fuerza de correccion. La planta nominal completa es de tercer orden, y a partir de una reduccion fisicamente justificada se disena una estrategia de control IMC-PID para disminuir la transmision de vibraciones hacia el sensor.
